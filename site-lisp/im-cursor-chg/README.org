#+title: Change cursor color for input method

This package is use for changing the cursor color when switching input method in Emacs.

** Usage
Put the following code in your Emacs init file.

#+begin_src emacs-lisp
(require 'im-cursor-chg)
(cursor-chg-mode 1)
#+end_src
