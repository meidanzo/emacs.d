* 检查清单
- 需要 Emacs 29 或更高版本
- 请阅读常见问题以禁用 [[http://www.vim.org][Vim]] 键位绑定
- 请阅读“键位绑定”一节以了解键位绑定
- Windows 用户最好下载捆绑了依赖的版本。例如，下载 "emacs-29.1-x86_64.zip" 而不是 "emacs-29.1-x86_64-no-deps.zip"
- 来自 [[http://melpa.org][MELPA]] 的不稳定软件包是 *不可见的* ，而来自 [[https://stable.melpa.org][MELPA Stable]] 的稳定软件包是可见的。请修改 =lisp/init-elpa.el= 中的变量 =melpa-include-packages= 来安装不稳定软件包
- 其他问题在常见问题中都有涉及
* 安装
请先删除 =~/.emacs= 。 =~= 表示[[https://en.wikipedia.org/wiki/Home_directory][主目录]]。

大多数用户需要遵循“常规方式安装”一节。

“安装稳定版本”一节 *当且仅当* 以下情况有用：
- 你没有网络访问
- 你从未使用过任何命令行程序

** 从远程仓库安装软件包（推荐）
有两种方式安装此配置（我推荐第一种）：

第一种方式是下载[[https://github.com/redguardtoo/emacs.d/archive/master.zip][最新配置]]并将其内容解压到 =~/.emacs.d= ，或者在 shell 中运行命令 =cd ~; git clone https://github.com/redguardtoo/emacs.d.git .emacs.d= 。

第二种方式是使用[[https://github.com/redguardtoo/emacs.d/archive/stable.zip][稳定配置]]，或者在 shell 中运行命令 =cd ~; git clone https://github.com/redguardtoo/emacs.d.git .emacs.d; cd .emacs.d; git reset --hard stable= 。

默认情况下，软件包会在 Emacs 启动期间自动安装。

有人反馈软件包仓库 [[http://melpa.org]] 在中国访问不畅。

不用担心。启动 Emacs 后，你可以对“是否临时切换到中国的更快的软件包仓库？”这一问题回答“YES”。请注意，启动后你可以修改 =init-elpa.el= 中的变量 =package-archives= ，以永久切换到中国仓库。
** 从本地稳定仓库安装软件包（可选）
- 下载 [[https://github.com/redguardtoo/emacs.d/archive/stable.zip]]
- 将其内容解压到空目录 =~/.emacs.d=
- 下载 [[https://github.com/redguardtoo/myelpa/archive/stable.zip]]
- 将 zip 解压到某处，例如 =~/projs/myelpa=
- 确保 =~/projs/myelpa= 中存在名为 =archive-contents= 的文件
- 取消 =lisp/init-elpa.el= 中包含 "myelpa" 的那一行的注释。路径 =~/myelpa/= 可以修改。
- 现在启动 Emacs！

现在你使用的是本地软件包仓库 =~/myelpa= 。

你可以通过修改 =lisp/init-elpa.el= 切换到 http://elpa.gnu.org 或 http://melpa.org 等在线仓库。
** 一步安装所有内容（可选）
将 [[https://github.com/redguardtoo/my-emacs.d-snapshot]] 的内容下载到 =~/.emacs.d= 。就这样。

不推荐日常使用，因为第三方软件包未针对最新 Emacs 优化。
** 第三方程序（可选）
*** 安装第三方程序
大多数命令行程序可以通过 =默认包管理器= 安装。

=默认包管理器= 可以是：
- Cygwin 上的 [[https://github.com/transcode-open/apt-cyg][apt-cyg]]
- [[https://www.msys2.org/docs/package-management/][MSYS2]] 的包管理器
- macOS 上的 [[https://github.com/mxcl/homebrew][homebrew]]
- Linux 上的任何包管理器（Debian/Ubuntu 上的 =apt= ，Redhat 上的 =yum= ，Arch 上的 =pacman= ，Gentoo 上的 =emerge= ……）

有些包管理器允许你为当前用户安装程序。例如，python 包管理器 =pip= 有 "[[https://packaging.python.org/tutorials/installing-packages/][--user]]" 选项。

* 使用
Emacs 原有配置或第三方软件包的配置都会得到尊重。

** 快速开始
在 Windows 上，你需要安装 Cygwin，它为 Emacs 提供命令行程序。Cygwin 可以安装在任何硬盘上，但强烈建议不要改变它相对于根驱动器的相对路径。

安装 Ctags（Universal Ctags 更好，Exuberant Ctags 也可以）。在 Windows 上，你可以通过 Cygwin 安装 Ctags。

运行 =fastctags= 的 =M-x fastctags-find-tag-at-point= 来导航代码。它使用 ctags 创建的 tags 文件。当你开始使用 =fastctags= 时，tags 文件会自动创建/更新。

运行 =M-x fastctags-grep= 在项目中搜索文本（grep）。项目根目录会自动检测。

运行 =find-file-in-project= 的 =M-x find-file-in-project-by-selected= 在项目中查找文件。项目根目录会自动检测。你也可以在 =.emacs= 中添加一行配置，例如 =(setq ffip-project-root "~/proj1/")= 。

使用 Ctags 创建的 tags 文件，代码自动补全开箱即用。

如果有任何关于配置的进一步问题，请在 =~/.emacs.d/lisp= 目录中用 [[https://en.wikipedia.org/wiki/Grep][grep]] 进行搜索.
** 更好的运行时性能
*** 为什么打开文件很慢
将下面的代码插入 =~/.custom.el= ，将 "/home/user1/your-file-path" 替换为你想打开的文件，
#+begin_src elisp
(defun profile-open-file ()
  (interactive)
  (profiler-start 'cpu)
  (find-file "/home/user1/your-file-path")
  (profiler-report)
  (profiler-stop))
#+end_src

运行 =M-x profile-open-file= 并阅读报告。
** 键位绑定
不要死记任何键位绑定。尝试 =M-x any-command-in-emacs= ，会显示其键位绑定的提示。

大多数键位绑定定义在 =lisp/init-evil.el= 中，少数键位定义在 =lisp/init-hydra.el= 中，后者使用了 [[https://github.com/abo-abo/hydra][Hydra]]。

在任意位置按 =C-c C-y= 调出默认的 hydra 菜单。

我推荐的教程中包含足够的命令相关信息。

此外，“[[http://redguardtoo.github.io/posts/how-to-be-extremely-efficient-in-emacs.html][How to be extremely efficient in Emacs]]”列出了我常用的命令。

按 =kj= 从 =evil-insert-state= 以及 Emacs 中的其他任何状态退出。它比 Vim 中的 =ESC= 或 Emacs 中的 =C-g= 高效得多。详情请在 =init-evil.el= 中搜索 =evil-escape= 。
* 常见问题
** 设置 Emacs 服务
使用 [[file:tools/start-emacs-daemon.sh]] 设置 emacs 服务。
*** macOS
创建 "~/Library/LaunchAgents/org.gnu.emacs.daemon.plist"，
#+begin_src xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>Label</key>
    <string>org.gnu.emacs.daemon</string>

    <key>ProgramArguments</key>
    <array>
      <string>/path/to/start-emacs-daemon.sh</string>
    </array>

    <key>RunAtLoad</key>
    <true/>

    <key>KeepAlive</key>
    <true/>

    <key>StandardOutPath</key>
    <string>/tmp/emacs-daemon.out</string>

    <key>StandardErrorPath</key>
    <string>/tmp/emacs-daemon.err</string>
  </dict>
</plist>
#+end_src
运行 =launchctl load ~/Library/LaunchAgents/org.gnu.emacs.daemon.plist && launchctl start org.gnu.emacs.daemon= 以在 macOS 上启用并启动 emacs daemon。
*** Linux
创建 "~/.config/systemd/user/emacs.service"，
#+begin_src confg
[Unit]
Description=Emacs text editor
Documentation=info:emacs man:emacs(1) https://gnu.org/software/emacs/

[Service]
Type=forking
ExecStart=/path/to/start-emacs-daemon.sh
ExecStop=/path/to/start-emacs-daemon.sh stop
Environment=SSH_AUTH_SOCK=%t/keyring/ssh
Restart=on-failure

[Install]
WantedBy=default.target
#+end_src
运行 =systemctl --user enable emacs.service && systemctl --user start emacs.service= 以在 Linux 上启用并启动 emacs daemon。

** 内存较小的电脑

** LaTeX-mode
支持 =LaTeX-mode= 的配置由 =init-LaTeX-mode.el= 提供。 在Linux 上面安装好 texlive-full, latexmk, zathura 软件包即可。它仅在 Linux 上测试过, 其他操作系统尚未验证。

需要注意的是，由于各类模式对插件的支持存在差异，目前不支持 =plain-tex-mode= 和 =doctex-mode= 。如有需要，请手动配置。

=init-LaTeX-mode.el= 支持预览 LaTeX 文件。在 GUI 环境中，要自动预览 =proof= 环境中的数学公式，需要从 =TeX-fold-env-spec-list= 中移除 =proof= ；否则必须手动运行 =preview-latex= 命令才能启用预览。

此配置与 =latexmk= 紧密集成，PDF 查看器通过 =latexmk= 调用。要在不做修改的情况下使用，请将以下内容添加到 =~/.latexmkrc= ：

#+begin_src perl
$pdf_mode = 5;
$pdf_update_method = 1;
$preview_mode = 1;
$preview_continuous_mode = 0;
$engine = 'xetex';
$pdflatex = 'xelatex -synctex=1 %O %S';
$lualatex = 'lualatex -synctex=1 %O %S';
$xelatex = "xelatex -file-line-error -halt-on-error -interaction=nonstopmode -synctex=1 %O %S";
$xdvipdfmx = "xdvipdfmx -E -o %D %O %S";
$go_mode = 1;
$bibtex_use = 2;
$pdf_previewer = 'zathura %O %S';
$clean_ext = "los synctex.gz xdv";
$env_clean = 1;
#+end_src

如果 Emacs 以 daemon 方式启动，请将以下内容添加到 =zathurarc= 以启用 PDF 正向和反向搜索：

#+begin_src shell
set synctex true
set synctex-editor-command "emacsclient --no-wait +%{line} %{input}"
#+end_src

有关更详细的实现和设计说明，请参考 =init-LaTeX-mode.el= 中的注释以及相关插件的文档。

* 提示

* 报告 Bug
请先查看 [[http://www.emacswiki.org/emacs/][EmacsWiki]] 和我的常见问题。

如果你仍然无法解决问题，
- 在 shell 中使用选项 =--debug-init= 重启 Emacs
- 在 Emacs 中运行 =M-x toggle-debug-on-error=
- 重现问题并将错误信息发送给我

启动 Emacs 的完整命令行是 =emacs -nw --debug-init= 。

如果你使用 [[https://emacsformacosx.com][Emacs for Mac OS X]]，命令行是 =/Application/Emacs.app/Contents/MacOS/Emacs -nw --debug-init= 。

如果是第三方软件包的问题，请将错误信息发送给原始开发者。

如果 *你确定* 这是我的 bug，请在 [[https://github.com/redguardtoo/emacs.d]] 提交报告。不要给我发邮件！

Bug 报告需要包含 *环境详情* 。
